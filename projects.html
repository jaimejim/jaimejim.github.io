Projects

A handful of side projects I maintain outside work. Mostly small things I build for myself, my family, or to test an idea end-to-end. Work at Ericsson lives elsewhere.

01 · Agentic systems

  • ad.jaime.win

    Agent Directory

    Live instance of a draft I-D for agent registration and discovery. Register agents, query against them, load the SKILL.md to try from an agent.

  • camara.jaime.win

    Camara Sandbox

    Agentic sandbox around CAMARA network APIs. A place to poke at network exposure from an LLM.

  • tertulia.jaime.win

    Tertulia

    Chat over a YouTube corpus using local distillation and a topic graph instead of chunk RAG. 202 videos in, 200 linked notes out, served from a single Cloudflare Worker.

  • coap agents

    Agentic IoT over CoAP

    Experiments wiring LLM agents to real constrained devices over CoAP, instead of pretending everything speaks HTTP + JSON.

02 · Home & kids

  • mates.jaime.win

    Mates

    Tiny maths practice site I built for my kids. Fast, no accounts, runs on whatever tablet is nearby.

  • recetario.jaime.win

    Recetario

    Family recipe book. Spanish-first, no ads, no tracking, no 2,000-word intro about someone's grandmother.

03 · Offline

  • capperi.fi

    Capperi

    Two pizzerias in Helsinki I co-own. Napoletana, wood-fired, not a side project in the software sense but definitely a side project.
