Projects

A handful of side projects I maintain outside work. Mostly small things I build for myself, my family, or to test an idea end-to-end. Work at Ericsson lives elsewhere.

01 · Agentic systems

  • ad.jaime.win

    Agent Directory

    Live instance of an IETF draft I wrote on agent registration and discovery. Register agents, search the directory, drive it from another agent via its skill file.

  • camara.jaime.win

    Camara Sandbox

    A sandbox to test how an LLM agent interacts with an API catalog it doesn't know a priori, given only intent, credentials, and an entry point. Using CAMARA as the catalog, the goal is to keep the ReAct loop secure and efficient with context provided inband.

  • tertulia.jaime.win

    Tertulia

    An experiment in chatting over a knowledge base derived from video transcriptions. Each video is distilled locally into a structured note with topic links, and questions are answered by walking the graph.

  • coap agents

    Agentic IoT over CoAP

    Extension of the Building Agentic IoT Systems talk. A general-purpose code agent over CoAP that discovers devices at runtime, learns their capabilities, and interacts with them with little a priori knowledge. Ongoing work on message and token optimization, and state-aware cached execution (slides 21, 23, 24).
